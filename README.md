# 🚗 Anime Cars Generator & Gumroad Publisher

Sistema completo para generar y publicar packs de imágenes de coches anime en Gumroad.

## 🎯 **INICIO RÁPIDO**

### **1. Generar Imágenes**
```bash
python anime_cars_generator.py
```
- Genera 8 imágenes por pack (optimizado)
- Crea solo carpetas (sin ZIP)
- Genera vista previa de cada pack

### **2. Publicar en Gumroad**
```bash
# DEFINITIVO: 100% Funcional Garantizado (RECOMENDADO)
python gumroad_final_publisher.py

# ALTERNATIVO: Guía interactiva paso a paso
python gumroad_single_publisher.py
```
